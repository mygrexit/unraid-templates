# unraid-templates

Community Applications templates for my self-hosted tools.

| Application | Source | Image |
|---|---|---|
| payback-coupon-activator | [GitHub](https://github.com/mygrexit/payback-coupon-activator) | `ghcr.io/mygrexit/payback-coupon-activator` |
| homebox-companion | [GitHub](https://github.com/Duelion/homebox-companion) | `ghcr.io/duelion/homebox-companion` |

Layout follows the official Community Apps starter: `ca_profile.xml` in the repository root,
one template per app in `templates/`, icons in `images/`.

Templates for third-party applications are maintained here as packaging only; please report application bugs to the upstream project.
